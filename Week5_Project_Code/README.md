# Week 5 — Data Visualization and Communication
Prepared by: Tushar Sharma

This project creates a set of labeled visualizations from the Retail Store Sales dataset and includes a notebook/script with the narrative and interpretation. The visual portfolio includes spend distribution, category totals, quantity vs spend, discount-group comparison, monthly trend, and payment-method counts.

## Run
`pip install -r requirements.txt`
`python src/week5_visual_storytelling.py`
Or open `notebooks/Week5_Data_Visualization.ipynb` and run all cells.
